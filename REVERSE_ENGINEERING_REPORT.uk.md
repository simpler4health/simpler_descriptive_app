# REVERSE_ENGINEERING_REPORT — simpler_descriptive_app

## A. Загальний діагноз

### Виявлена архітектура
Додаток R Shiny для дослідників, щоб досліджувати змінні SIMPLER (Swedish Infrastructure for Medical Population-Based Life-Course and Environmental Research), Уппсальський університет. Структура:

- `app.R`: UI, server, логування використання, опціональний вхід
- `R/`: модулі (explore_variable_module.R, faq_search_block.R, _disable_autoload.R)
- `meta_data/`: списки змінних на dataset (11 файлів CSV)
- `faq/`: вміст FAQ (simpler_faq.csv)
- `renv.lock`: точні версії пакетів R
- `Dockerfile`: образ для SciLifeLab Serve
- `.github/workflows/docker.yml`: CI для збудь та публікації образу Docker

### Технології та залежності
- R 4.3.2
- Пакетки: shiny, shinyjs, shinyWidgets, shinymanager, DT, compareGroups, ggplot2, Hmisc, ComplexUpset, openxlsx, digest, openssl, rgeolocate, jsonlite, htmltools
- Docker

### Стан підтримки
Гałтьова гілка: main. Репозиторій: https://github.com/simpler4health/simpler_descriptive_app. Автоматична збірка через GitHub Actions + GHCR.
